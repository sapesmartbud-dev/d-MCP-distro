# Íconos SAPÉ

Generados desde los SVG solo-emblema de `assets/logos/desktop_icon_base`.

## Nomenclatura

- `dark-*`: ícono con fondo oscuro, recomendado para aplicaciones de escritorio.
- `trans-*`: ícono transparente, recomendado para web, favicon, PWA y overlays.
- `app.ico`: ICO multiresolución para escritorio; alias de `dark.ico`.
- `favicon.ico`: ICO multiresolución para web, basado en el ícono transparente.
- `apple-180.png`: Apple touch icon.
- `pwa-192.png` y `pwa-512.png`: íconos para manifest PWA.

## Tamaños

- PNG: 16, 24, 32, 48, 64, 96, 128, 180, 192, 256, 512, 1024 px.
- ICO: 16, 24, 32, 48, 64, 128, 256 px, más archivos ICO multiresolución.
