# Contributing to SAPÉ d-MCP

Thank you for your interest in SAPÉ d-MCP.

## Fork freely

SAPÉ d-MCP is free software under the **GNU General Public License, version 3 only** (`GPL-3.0-only`). Anyone may fork it, modify it and publish that fork without asking permission. A fork is a perfectly good outcome in its own right, and it never has to come back here.

## Pull requests

Pull requests to <https://github.com/sapebud/d-mcp> are welcome. Integrating them is **at the author's discretion**. A pull request may be merged as it is, adapted, partly taken, or declined. There is no obligation to review, answer or merge it, and no timeline. If a change matters to you, keep it in your fork.

## If you distribute a fork

The GPL asks the following of anyone who distributes a modified version, as source or as a binary:

- [ ] Include the full [`LICENSE`](LICENSE) file.

- [ ] Mark the files you modified, with the date of the change (§5(a)).
- [ ] License the whole work under GPL-3.0-only (§5(c)).

## Security issues

Please don't report vulnerabilities in public issues. Email **info@sapebud.com** instead.
